## 📖 **Introduction**  

#### *RLibrary+* is a redesigned Batangas State University Library System that aims to provide a modern, user-friendly, and fully responsive platform for students, faculty, and staff. Addressing issues like outdated design, limited search filters, and the lack of digital borrowing, the system will feature an organized search interface, improved filtering options, mobile compatibility, and a built-in online borrowing. With integrated analytics for tracking usage and trends, *RLibrary+* will centralize academic services, streamline workflows, and enhance the overall library experience.

---

## 🔍 **Observations**  

📌 Current challenges faced by users:  
- ❌ Borrowing system is not integrated 
- 🧭 Limited search and filter options    
- ⏳ No access to history or usage data
- 📱 No mobile responsiveness 

These issues reduce overall engagement and make the system frustrating for daily use.    

---

## ❗ **Problem Statement**  

The current system:  
- 🗂️ Is outdated and visually cluttered  
- 🔍 Lacks search flexibility  
- 📚 No built-in digital borrowing
- 🧾 Doesn't support borrowing history tracking  
- 📉 Has no analytics or decision support    

Since students and faculty heavily depend on library services, these limitations directly affect academic productivity and overall user satisfaction.  

---

## 🎯 **Project Objectives**  

**Main Goal**  
Redesign the library system into a **modern, user-friendly, and data-driven platform** for improved library services.  

**Specific Goals**  
- 🎨 Ensure full mobile responsiveness for seamless access on any device  
- 📚 Integrate a built-in online borrowing system with Notifications, bookmarks, Borrowing history
- 📊 Provide analytics for usage tracking and decision support  

---

## ✅ **Functional Requirements**  

### 1. 👨‍🎓 **Student Functions**  
- 🔐 Log in
- 🔍 Search materials by:  
  - 📘 Title  
  - ✍️ Author  
  - 🏷️ Subject or Series  
- 🎯 Filter results by:  
  - 🏫 Campus  
  - 📂 Material type  
- 📖 View book details (title, author, campus, material type, and series)  
- 🧾 Borrow or request books online  
- 📜 Access Bookmarks and borrowing history  

---

### 2. 👩‍💼 **Library Staff Functions**  
- 🔑 Admin login
- 🧾 Add new resources  
- ✅ Approve or reject borrowing requests
- 📚 Update material status (Returned)
- 🔎 Access detailed borrowing logs.
- 📊 View system analytics
